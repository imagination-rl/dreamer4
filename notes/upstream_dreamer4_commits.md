# Upstream dreamer4 commits after 2026-08-01 that this fork does not have

Source: https://github.com/lucidrains/dreamer4/commits/main/. Checked on 2026-10-03. This fork reports dreamer4 version 0.18.1, which is older than all of these commits. The diffs are at `https://github.com/lucidrains/dreamer4/commit/<sha>`.

The state-observation runs (HalfCheetah, `train/train_gym.py`) do not use any of the fixed code paths. The run path of each item was checked. **Image observations use several of these paths.** Before you train on images, apply the items marked "images", then test them.
